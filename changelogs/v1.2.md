# :tools: CHANGELOG - v1.2.0

## :new:  Added
- **Global `tick()` Engine Updates**: 
  - Added background loop handler for persistent ParticleFX state `state.particle_loop_state`.
  - Added background state machine for `active_paparazzi` NPC chase sequences.
- **Local Vehicle Acrobatics**:
  - Implemented `ENTITY.APPLY_FORCE_TO_ENTITY` impulse handlers for `Jump`, `Left Kickflip`, `Right Kickflip`, and `Backflip` in the main `Vehicle Options` menu.
- **Online Players Menu Expansion**:
  - Added **General**: `Spectate Player`, `Copy Outfit`, `GPS to Player`.
  - Added **Remote Vehicle Options**: `Fix/Wash`, `Randomize Paint`, `Max Performance Upgrades`.
  - Added **Nice Options**: `Care Package`, `Hire Bodyguard`, `Spawn T20`, `Give Chauffeur`, `Escort Helicopter`, `Snack Drop`, `Weapon Drops`.
  - Added **Funny Options**: `Giant Sombrero`, `Taunt Player (Clowns)`, `Stunt Ramp Spawner`, `Fake Alien Abduction`, `Traffic Cone Hat`, `Animal Swarm`, `Clone Dancer`.
  - Added **Unique Options**: `Paparazzi Swarm`, `Fake Airdrop`, `Fake Police Raid`, `UFO Stalker`, `Personal Raincloud`.
  - Added **ParticleFX Submenu**: Added 13 specific FX toggles with a background loop boolean (Fireworks, Money Rain, Blood Geysers, Alien Beams, etc).

## :wrench: Refactored
- Extracted ped/object/vehicle spawning logic into robust helper functions: `safe_spawn_ped`, `safe_spawn_object`, `safe_spawn_vehicle` with built-in model streaming safety (`request_model`).
- Extracted ParticleFX logic into `request_particle_dict` and `play_particle_on_entity` to ensure dicts are fully loaded before rendering.

## 🐛 Bug Fixes
- **Asynchronous Model Streaming**: Wrapped all remote entity spawners (Paparazzi, Bodyguards, Vehicles) inside `script.run_in_fiber()` to prevent synchronous model loading `script.yield(0)` from freezing the Ethereal UI context thread.
- **Syntax Resolution**: Removed a rogue `end` statement and strictly parsed the entire Lua script for syntactic compliance. It just works now.. sorry
